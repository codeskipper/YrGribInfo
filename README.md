# YrGrib 

Get the best weather data for your sailing trip in Norway in the best GRIB viewer app.

YrGrib is a companion app for sailors to fetch weather model data from the Norwegian Meteorological Institute (MEPS) for a GRIB viewer app.  Wind data is normally used, you can alternately select current or wave data.

Select the area for your trip, favourite or current location. Crops to the size needed. Notification for new forecast data available. Works with Shortcuts.

Share with the GRIB viewer of choice, LuckGrib is the best candidate in our experience.
