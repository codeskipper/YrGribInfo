# YrGrib 

Get the best weather data for your sailing trip in Norway in the best GRIB viewer app.

YrGrib is a companion app for sailors to fetch weather model data ([MEPS](https://docs.api.met.no/doc/locationforecast/datamodel.html)) from the Norwegian Meteorological Institute [api.met.no](api.met.no) for a GRIB viewer app.  Wind data is normally used, you can alternately select current or wave data.

Select the area for your trip, favourite or current location. Crops to the size needed. Notification for new forecast data available. Conveniently works with Shortcuts on your iPhone or iPad.

Share with the GRIB viewer of choice, LuckGrib is the best candidate in our experience. To be fair, it is the only app on iOS I've found that will import a Gribfile.

YrGrib is available for both iPhone, iPad and Mac.
